    How to Use This Book

    Every training day follows the same five-phase preparation sequence before the main session begins. Each phase builds on the last — raising heart rate, restoring joint range, switching on the right muscles, and priming the nervous system for the specific movement pattern trained that day.

    1. Pulse (Raise) — A short cardio burst to raise heart rate and core temperature.
    2. Mobilize — Joint-by-joint controlled mobility work for the regions used that day.
    3. Activate — Low-load drills that switch on the muscles the day's lifts depend on.
    4. Potentiate — Explosive or high-intent movement to prime the nervous system.
    5. Perform — The main working sets for the day.

    Perform is organized into lettered blocks of exercises. Exercises paired within a block may be supersetted (performed back-to-back with minimal rest) or run as straight sets — use judgment based on the client's conditioning and equipment access.

    ★ Signature Hold

    Each day carries one defining isometric hold that reinforces the movement pattern trained: a quick, repeatable checkpoint for how well the body is moving that day.

    ◆ Core Slot

    A short Core slot (Leg Drops, Dead Bug, Torso Rotations, Pallof Press or Suitcase Carry — 2 × 10 each side where unilateral) sits between Mobilize and Activate on Monday, Thursday, and Saturday — the non-leg days, since Tuesday and Friday already carry heavy core-bracing demand from squats, hip hinges, and Copenhagen Plank. Wednesday is a full rest day. (Updated v2.9 — Core-slot days shifted to Monday/Thursday/Saturday when Wednesday and Friday's former sessions merged into Thursday and Wednesday became a rest day.)

    Every drill named across Pulse, Mobilize, Core, Activate, and Potentiate is collected in one place — each linked to a how-to video — in the Movement Prep Drill Index below, rather than being relinked inline every time it recurs.

    Glossary of Terms

    TermDefinition
    CARsControlled Articular Rotations — slow, deliberate movements through a joint's full range of motion to improve mobility and motor control.
    IAPIntra-Abdominal Pressure — pressure created within the abdominal cavity by bracing the core muscles (transverse abdominis, pelvic floor, diaphragm) to stabilize the spine during heavy lifts.
    HIITHigh-Intensity Interval Training — short bursts of maximum effort followed by brief rest periods.
    SupersetTwo exercises performed back-to-back with minimal to no rest in between.
    Alternate (alt)A substitute exercise that can be used in place of the primary exercise if equipment is unavailable or for individual client needs.
    PotentiationA high-intensity, explosive movement performed immediately before a working set to prime the nervous system for heavier loads.
    BracingThe active contraction of core musculature to create spinal stability during lifting, often coordinated with breath.
    Anti-MovementCore exercises that resist a specific force (e.g., Anti-Extension resists spinal extension) rather than producing movement.

    Rest Period Guide

    Every estimated session duration in this manual assumes a 60–90 second rest between sets and between superset pairs, unless a specific rest interval is written into the exercise itself (e.g., HIIT Rower's 60 sec between rounds). This section makes that assumption explicit and gives a standard rest recommendation for each block type.

    If you're time-pressedAdjust the weight — not the rest. The session-length estimates hold only if rest stays in the 60–90 second band. Rather than stretching rest to 3–4 minutes to handle a heavier weight, drop the load enough to comfortably finish each set within that window. This keeps supersets genuinely supersetted and keeps the written session-duration estimates accurate.
    Block TypeStandard RestWhy
    Block A — Primary Compound Lift90–120 sec between setsHeaviest load, lowest reps (4–8 range) in the session; full recovery protects bar speed and technique on the lift that drives the week's progress.
    Block B / C — Secondary Compound & Isolation60–90 sec between sets or supersetsThe default this manual's session-duration estimates are built on — enough recovery for quality reps without inflating session length.
    Block D / E — Accessory45–60 sec between setsHigher reps (12–20), lighter load, lower per-set fatigue — shorter rest keeps these in their intended "light-touch" role.
    Core Slot (Leg Drops, Dead Bug, Torso Rotations, Pallof Press / Suitcase Carry)30–45 sec between sets or sidesLow systemic fatigue by design; brief rest keeps this slot efficient between Mobilize and Activate.
    Force Transfer / Potentiate (Medicine Ball Throws, plyometrics)Full recovery — 2–3 min between setsA power quality, not a density quality: explosive intent depends on near-full recovery. Treat this as the stated exception to the 60–90 second default.
    Signature HoldNo rest neededA single all-out isometric attempt performed once, as a movement-quality checkpoint — not a multi-set exercise.

    Appendix — Core Training System

    The full function-by-function reference behind the Core Programming Notes embedded in Part One

    Core Musculature — Quick Reference

    The muscles behind the ten functions below, for cueing and client education.

    Erector Spinae

    Three-muscle group running up the back; extends the trunk back to upright after bending, and assists side bending and neck rotation.

    Rectus Abdominis

    The "six-pack" muscle; produces trunk (spinal) flexion.

    Internal/External Obliques

    Produce trunk rotation and lateral flexion.

    Transverse Abdominis

    Wraps around the front/sides of the trunk; the primary pelvic and spinal stabilizer — key to bracing and IAP.

    Multifidus

    Deep spinal stabilizer running along the vertebrae; supports the spine segment-by-segment.

    Supporting Cast

    Pelvic floor, diaphragm, glutes, and the hip-attaching muscles (hamstrings, hip flexors, adductors) all contribute to core function even though they aren't "abs."

    The Two Categories of Core Function

    Core function splits into two categories: Movement-Production — what the trunk actively does — and Anti-Movement / Stability (the McGill model) — what the trunk resists under an external force.

    Movement-ProductionAnti-Movement / Stability
    FlexionAnti-Flexion
    ExtensionAnti-Extension
    Lateral FlexionAnti-Lateral-Flexion
    RotationAnti-Rotation

    Two additional functions sit outside this 2×4 grid: Force Transfer (rotational power moving through the trunk, lower body to upper body) and Bracing / Intra-Abdominal Pressure (the breath-driven stiffness created by the deep inner unit — transverse abdominis, multifidus, diaphragm, pelvic floor). Neither produces nor resists a specific plane of motion; they're closer to how the other eight functions actually get executed.

    Dosage by Function Type

    Function TypeDosage Guidance
    Movement-ProductionModerate reps (8–15), controlled tempo, moderate load. This is strength through a range of motion.
    Anti-Movement / StabilityDosed as time, not reps — 20–45 s holds with a breathing focus. The training effect is endurance of stiffness, not strength through range.
    Force TransferA power quality. Low reps, full recovery between sets, explosive intent — program it early in the session, not as a finisher.
    Bracing / IAPNot a slot — a skill layered into every heavy lift via cueing, not just isolated to a single exercise.

    Cautions

    Lateral Flexion / Flexion / Extension were likely an intentional gap, not an oversight — and they have been added accordingly. The program's own revision notes record that Weighted Side Bends was tried in the Core slot and deliberately replaced with Pallof Press "to keep the work anti-rotational rather than adding spinal loading on top of an already loading-heavy week." v1.6.1 respects this caution by placing these three functions on Sunday Recovery — the only day without competing spinal load — and keeping them light (2 × 10–12).
    Anti-Rotation and Anti-Extension look strong on paper — but that strength may be compromised if Bracing/IAP isn't cued underneath them on the week's squat and hinge days. v1.6.1 adds the cueing directly to those days' Core Programming Notes. (v2.2 — Tuesday takes over the squat-day role from Monday under the split restructure. v2.9 — the hinge-day role moves from Thursday to Friday when Thursday absorbs the former Wednesday/Friday sessions.)

    Training Formats

    The three interval formats referenced throughout this manual, and how each maps onto the Custom Timer above.

    PROTOCOL

    Tabata

    A fixed, named protocol from a 1996 study on Japanese speed skaters: 20 seconds at true maximal effort, 10 seconds rest, repeated for 8 rounds — 4 minutes total. It's the format behind this tab's built-in Tabata clock.

    The 20/10 timing only counts as "Tabata" if the work interval is genuinely all-out — pacing it like a moderate HIIT round misses the point of the protocol.

    10s prep · 20/10 · ×8
    CATEGORY

    HIIT

    High-Intensity Interval Training is the umbrella category, not one fixed timing — short bursts of hard effort alternated with easier recovery, at whatever work/rest ratio suits the exercise and the client's conditioning. Tabata is technically one specific HIIT protocol.

    Common ratios: 20/10, 30/30, 40/20, 1:1 work-to-rest. This manual's HIIT Rower and Potentiate throws are HIIT-style but don't follow the strict Tabata timing.

    10s prep · 40/20 · ×8
    FORMAT

    EMOM

    "Every Minute On the Minute" — a fixed number of reps performed at the start of each 60-second window, then whatever time is left over is rest. The faster the reps get done, the more rest that round; the interval length never changes.

    The timer's Work/Rest split can only approximate this: set Work to a target rep-cap time and Rest to whatever's left in the minute (e.g. 40/20). True EMOM rest is self-paced, not fixed.

    10s prep · 40/20 · ×10
